# Простой сервер автосалона 🚗

Учебный проект на **Node.js + Express + MongoDB**. Здесь можно добавлять машины, смотреть список, менять данные и удалять машины. Код специально сделан проще: маршруты находятся в одном файле `server.js`, а модель данных — в `models/Car.js`.

## Как запустить

1. Установи **Node.js** (версия 20.19 или новее) и **MongoDB**.
2. Запусти MongoDB локально (адрес по умолчанию: `mongodb://127.0.0.1:27017`).
3. Открой терминал в этой папке и выполни:

   ```bash
   npm install
   npm start
   ```

4. Открой в браузере: <http://localhost:5000/api/cars>.

По умолчанию используется база данных `cars`. При необходимости можно указать другую базу в переменной окружения `MONGO_URL`, а порт — в `PORT`.

## Какие есть запросы

| Метод | Адрес | Что делает |
| --- | --- | --- |
| GET | `/api/cars` | Список всех машин |
| GET | `/api/cars/:id` | Одна машина |
| POST | `/api/cars` | Добавить машину |
| PATCH | `/api/cars/:id` | Изменить машину |
| DELETE | `/api/cars/:id` | Удалить машину |

**Пример добавления машины:**

Отправь `POST http://localhost:5000/api/cars` с заголовком `Content-Type: application/json` и телом:

```json
{
  "brand": "Toyota",
  "model": "Camry",
  "year": 2020,
  "price": 2100000
}
```

После добавления машина получит свой `_id`. Его можно использовать для изменения или удаления. Например, `PATCH /api/cars/ID_МАШИНЫ` с телом `{ "price": 2000000 }`.

Для удобства примеры всех запросов есть в файле `requests.http` (подходит для расширения REST Client в VS Code). В Postman можно отправлять те же запросы.

## Структура проекта

```text
cars_server_simple/
├── models/
│   └── Car.js       # Как выглядит машина в базе
├── server.js        # Запуск сервера и все запросы
├── package.json     # Зависимости
├── package-lock.json # Версии зависимостей
├── requests.http    # Примеры запросов
└── README.md        # Инструкция
```

**Важно:** это API-сервер, не сайт с кнопками. Для проверки используйте браузер для GET-запросов или Postman / REST Client для остальных запросов.
